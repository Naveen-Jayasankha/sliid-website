# Sri Lanka Institute of Interior Designers Website

Official multi-page website concept for the Sri Lanka Institute of Interior Designers (SLIID).

## Pages

- Home
- About
- Governance
- Membership
- Member Directory
- Education
- News & Events
- Awards
- Publications
- Contact

The website is deployed automatically through GitHub Pages.

## Backend

The `backend` directory contains the PHP 8.1 + MySQL administration system prepared for future cPanel deployment. It includes the installer, secure administrator portal, member directory, news, events, publications, enquiries, membership applications, uploads and public JSON API.

GitHub Pages publishes only the `dist` directory. The backend source is stored in GitHub but must be deployed to a PHP-enabled cPanel subdomain before it can run.
